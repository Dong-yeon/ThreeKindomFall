## 1. 메가봉크

| 시스템 | 내용(조사) | 비고 |
|---|---|---|
| 캐릭터 | 약 21명. 시작 무기 1 + 고유 패시브 1. 캐릭터 = 직업 역할(별도 직업 체계 없음). 시작 무기를 상점에서 사면 캐릭터 해금 | |
| 무기 · 비전서(tome) | 무기 약 30종(레벨 최대 40), 비전서 약 26종(능력치 강화, 레벨 최대 99, 처음 10종 · 나머지 해금). 칸 수 제한(퀘스트로 칸 추가) | |
| 아이템 | 약 86종. 맞힐 때 확률 발동(독 40% · 빙결 7.5% · 번개 25% + 기절 · 폭발 8%), 처치 시 발동(미사일 20%), 발동 굴림 +1(램프), 구슬 주기적으로 끌어오기 등 | 빌드의 핵심 |
| 등급 · 행운 | 일반 → 고급 → 희귀 → 영웅 → 전설. 행운(네잎클로버 · 여우 · 행운 비전서)이 높은 등급 확률을 올림 | 레벨업 카드 · 상자 · 성소 모두 |
| 성소(맵 오브젝트) | 충전 성소(서 있으면 충전 → 능력치 고르기, 황금은 전설), 모아이 성소(아이템 고르기, 황금은 전설 확정), 도전 성소(정예 소환 → 이기면 상자), 흡수 성소(경험치 끌어옴) | 맵을 돌아다닐 이유 |
| 상자 | 금화로 여는 상자(열수록 비싸짐), 보스 · 정예 · 미니보스는 무료 상자 | 금화 = 판 안 재화 |
| 능력치 | 최대 HP · 회복 · 오버힐 · 쉴드(5초 뒤 재충전) · 아머 n/(0.75+n) · 회피 n/(1+n) · 생명 흡수 · 가시 · 대미지 · 치명타(100% 넘으면 오버 크리티컬) · 공속 · 발사체 수 · 반사 · 크기 · 발사체 속도 · 지속 · 엘리트 대미지 · 넉백 · 이동 · 추가 점프 · 점프 높이 · 행운 · 난이도 · 픽업 범위 · XP · 금화 · 은화 · 엘리트 등장 · 파워 업 | 출처 3겹: 캐릭터 스탯 × 비전서 × 성소 |
| 판 흐름 | 약 10분. 탐험 · 성장 → 보스 포털을 찾아 보스 → 시간이 지나면 '마지막 대군' | |
| 메타 진행 | 은화(판에서 모음)로 상점에서 해금. **퀘스트**를 깨면 상점에 보상이 열림. 퀘스트 총수로 기능 해금: 새로고침 20 · 무기 칸 25 · 건너뛰기 30 · 비전서 칸 35 · 제외(banish) 40 | 해금 조건 예: 도전 3번 → 모루, 민첩 비전서 Lv5 → 터보 양말, 적 1000 빙결 → 서리걸음 비전서 |
| 이동 | 점프 · 미끄러지기 · 버니합 · 대각선 · 카메라 회전 가속 | 숙련 요소 |

## 2. 뱀파이어 서바이버

| 시스템 | 내용(조사) | 비고 |
|---|---|---|
| 무기 · 패시브 칸 | 무기 6 + 패시브 6. 무기 최대 레벨 보통 8 | |
| 진화 | **무기 최대 레벨 + 짝이 되는 패시브 + 10분 뒤 보스 상자** → 진화 무기(일부는 패시브 2개). 진화하면 패시브가 소모되기도. **합체(Union)**: 무기 둘이 하나로 합쳐 칸이 빔 | 우리 '오의'(초식 2 + 심법 1)와 같은 구조 |
| 상자 | 보스 · 정예 상자는 아이템 1 · 3 · 5개 | 다 채우면 금화 · 고기(회복) |
| 바닥 줍기 | 고기(회복) · 금화 · 자석(구슬 전부 끌어옴) · 묵주(화면 적 처치) · 시계(적 정지) 등 | 2D판에도 고기만두 · 자석 · 폭탄 있었음 |
| 아르카나 | 판 시작 · 중간에 고르는 판 전체 규칙 카드(22종). 대부분 특정 캐릭터로 Lv 50 달성 · 특정 맵 N분 생존으로 해금 | 빌드 방향을 크게 바꿈 |
| 파워업 상점 | 금화로 모든 캐릭터에 영구 능력치(최대 체력 · 회복 · 피해 등). 되돌려 받기 가능 | 우리 2D판 '대장간 · 재능'과 같은 자리 |
| 유물 · 해금 | 맵에 숨은 유물 = 영구 수집(아르카나 · 무한 모드 · 한계 돌파 · 상인 등 시스템 해금). 해금 메뉴가 사실상 진행 안내(과제 목록) | 해금 조건 예: 시계 20개 → 맵, 고기 500개 → 맵 |
| 한계 돌파 | 최대 레벨 뒤에도 계속 강화(진화하면 초기화) | 후반 숫자 |

## 3. 우리 게임과 대응

| 시스템 | 우리(godot3d 지금) | 판단 |
|---|---|---|
| 캐릭터 = 시작 무기 + 고유 패시브 | **있음**(장수 = 시작 초식 + 고유 심법 + 절기 + 경공) | 유지 · A안: 시작 장비 · 유비, 관우 해금 |
| 무기 칸 · 패시브 칸 | 추가 초식 3칸 · 심법(칸 없음) | 칸을 정함(초식 4 · 심법 4) — 칸 추가는 해금 |
| 진화 | **있음**(오의: 초식 2 + 심법 1) | 유지. 추가 초식에도 진화(뱀서식 '무기 최대 + 짝 심법') |
| 아이템(발동 효과) | 없음 | **들여옴** — '보물'(맞힐 때 독 · 빙결 · 번개, 처치 시 폭발 등) |
| 등급 · 행운 | 없음 | **들여옴** — 레벨업 카드 · 상자 등급 |
| 성소 | 진영(정예 → 상자)만 | **들여옴** — '제단'(서 있으면 능력치 고르기) · '도전 깃발'(정예 소환) |
| 능력치 | 7종(무력 · 갑옷 · 신속 · 군량 · 자석 · 강건 + 무기 강화) | **늘림** — 회피 · 치명타 · 쉴드 · 흡성 · 반탄 · 지속 · 넉백 · 발사체 수 · 엘리트 · XP, 아머 · 회피는 수확 체감 공식 |
| 판 안 재화 · 상자 | 상자 무료 | 금전(동전) — 상자를 사서 엶 |
| 바닥 줍기 | 구슬 · 상자 | 고기만두 · 자석 · 진천뢰(화면 정리) · 시계(정지) — 2D판에 있던 것 |
| 메타 재화 · 해금 | 없음(2D판엔 대장간 · 재능 · 저장 있음) | **들여옴** — 은전 + 과제 목록 → 장수 · 초식 · 보물 · 기능 해금 |
| 파워업 상점 | 없음 | 군영(2D판 대장간 · 재능 이름을 이어받음) — 은전으로 영구 강화 |
| 아르카나 | 없음 | 나중 — '병법서'(판 규칙 카드) |
| 마지막 대군 · 보스 | **있음**(9분 대군 · 여포) | 유지 |
| 점프 · 이동 기술 | 경공(돌진 · 이단 도약) | 나중 — 지형 높낮이가 생기면 |

## 4. 들여올 순서(제안)
1. **메타 기반 + A안**: 저장(`user://save3d.json`), 판 끝 은전, 과제 목록(해금 조건) · 해금 알림, 시작 장수 장비 · 유비 · 관우 해금(여포 처치), 별 다시(장비 ★ · 유비 ★★ · 관우 ★★★), 잠긴 초식 · 심법은 카드에 안 나옴, 선택 화면 잠금 표시.
2. **능력치 확장 + 카드 등급**: 회피 · 치명타(오버 크리티컬) · 쉴드 · 흡성 · 반탄 · 지속 · 넉백 · 발사체 수 · 엘리트 · XP, 수확 체감 공식, 일시정지 스탯 창, 카드 등급(일반~전설) · 행운, 새로고침 · 건너뛰기 · 제외(과제 수로 해금).
3. **보물 · 제단 · 금전 상자 · 바닥 줍기**: 발동 효과 보물 10종 안팎, 맵 제단(능력치 고르기) · 도전 깃발, 금전으로 여는 상자(점점 비싸짐), 고기만두 · 자석 · 진천뢰 · 시계.
4. **군영(영구 강화) · 병법서(판 규칙 카드) · 추가 초식 진화 · 한계 돌파**.
