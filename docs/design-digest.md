# 설계 다이제스트 — 3D 생존형 + 삼국지 + 무공

> 결정의 근거는 커밋이 아니라 이 문서와 `docs/decision-log.md`(D-274~)에 남긴다. 미완 항목은 `docs/status.md`.
> 작업 제목 '삼국봉크'는 **문서에서만** 쓴다. '봉크'는 레퍼런스 게임의 고유 용어라 CLAUDE.md 규칙상 게임 화면에 넣지 않는다.

## 1. 컨셉
- 3D 생존형(로그라이크) 한 판 10분: 시간이 갈수록 적 떼가 커지고 9분부터 마지막 대군 → 10분을 버티면 승리(`godot3d/data/waves.gd`).
- 삼국지 장수 + **무공 체계**(초식 · 심법 · 내공 · 절기 · 오의 · 경공 · 주화입마)로 장수마다 손맛을 다르게.
- 첫 스테이지는 황건적 토벌(잡병 웨이브). 보스는 호뢰관 여포(다음 단계).
- 엔진: Godot 4.7 · GDScript · Compatibility 렌더러, PC 가로(모바일 고려 안 함, D-274). 2D판 `godot/`은 따로 둔다.

| 내공 | 고유 자원. 적을 맞히거나 쓰러뜨리면 참(초식 · 의용군이 맞혀도), 절기에 씀 | `data/martial.gd` · `scripts/martial/neigong.gd` |

| 경공 | 이동기(돌진 / 도약 · 이단 도약), 장수마다 거리 · 무적 · 충전이 다름 | `data/heroes.gd` qinggong · `scripts/player.gd try_dash` |

- 조작(PC): 이동 WASD · 경공 Shift · 절기 Space(K도) · 레벨업 1 · 2 · 3.

## 3. 세 장수 킷 (수치는 데이터 파일)
| | 장비 ★ 입문 | 관우 ★★ | 유비 ★★★ 대기만성 |
|---|---|---|---|
| 역할 | 탱커 · 광폭 | 광역 · 묵직 | 소환 · 지원 |
| 시작 초식 | 장팔사모 — 길게 찔러 꿰뚫음 | 청룡언월도 휩쓸기 — 느리고 넓은 부채꼴 | 쌍고검 — 가까운 적 둘에게 칼을 날림(약함) |
| 고유 심법 | 광폭 — 잃은 체력만큼 공격 ↑(최대 +80%) | 위풍 — 휩쓸기 범위 +15% · 밀어내기 +30% | 인덕 — 의용군 공격 · 체력 +20%(레벨마다 +16%) · 근검 초당 회복 +0.6 |
| 절기 | 사자후 — 둘레 적 기절 + 크게 밀침 | 언월참 — 앞으로 날아가는 넓은 참격파 | 의용군 소환 — 쓸 때마다 의용군이 늘어 판 끝까지 남음(누적). 한 번에 1 + 레벨 × 0.06명, 최대 12 + 레벨 × 0.5명 |
| 오의 | 장판교 호령(장팔사모 속공 3 + 화계 2 + 갑옷 2) | 청룡파천(청룡언월도 단련 3 + 회전 언월 3 + 무력 2) — 참격파 셋 | 도원의 맹세(칼 한 자루 더 2 + 화살 비 2 + 강건 2) |
| 경공 | 돌격 — 중간 거리 · 무적 0.35초 | 돌진 — 짧고 무거움, 부딪힌 적을 밀침 | 이단 도약 — 2회 충전, 공중에서 한 번 더 |

### 유비 '대기만성' 곡선을 만드는 장치(D-286)
- 시작 초식 쌍고검은 약하게(칼 1자루 · 피해 1.7 · 재사용 0.65초).
- 의용군 힘은 **레벨에 크게 기댐**: 기본 피해 2.0에 인덕 배율(1.2 + 레벨 × 0.16) — 레벨 8에선 약하고 레벨 45 넘으면 강함.
- 의용군 체력은 **비율**로 들고 최대 체력 = 60 × 인덕 배율 → 레벨이 오르면 이미 있는 병사도 단단해짐. 붙은 적이 없으면 초당 5% 회복.
- 한 번에 소환하는 수 · 최대 수가 레벨 따라 늚 → 초반 군대는 작고 후반 군대는 큼.
- 의용군은 **전용 맞음 대기**(`horde.ally_cd`)를 씀 — 장수 공격과 같이 쓰면 화계 등에 막혀 휘두름의 43%가 헛침.

## 3-1. 황건적 스테이지 · 적 · 보스 (2단계, D-287~291)
- **한 판:** 140×140 맵(가장자리 목책) · 진영 3곳(장보의 진 · 장량의 진 · 황건 제단) · 10분을 버티면 **호뢰관 여포**. 여포를 쓰러뜨리면 승리.
- **진영:** 살아 있으면 잡병 생성의 15%가 그 진영에서 나옴. 지키는 정예를 쓰러뜨리면 그 진영 생성이 멈추고 보상 상자(레벨업 카드 + 체력 30). 화면 가장자리에 진영 방향 · 거리 표시.
- **잡병 4종**(`data/enemies.gd`): 졸병 · 궁병(거리 8 유지 · 날아가는 화살 — 피할 수 있음) · 돌격병(빠르고 약함) · 방패병(느리고 단단 · 잘 안 밀림). 2분부터 섞이고 9분엔 졸병 55%.
- **적장**(`scripts/foe/foe.gd` · `data/foes.gd`): 정예 · 보스 공통. 붉은 예고 → 실행(부채꼴 · 돌진 · 발밑 원 · 퍼지는 고리 · 잡병 부르기). 장수의 모든 공격이 `horde.targets`로 적장도 맞힘. 정예는 처음 맞을 때 판 시각만큼 단단해짐(늦게 가면 더 셈).
  - 장보: 돌진 + 휩쓸기 / 장량: 넓은 휩쓸기 + 부르기 / 황건 도사: 발밑 화염 원 + 고리
  - 여포: 휩쓸기 200° · 돌진 14m → 체력 50% 아래 빨라지고 '패왕 진각'(고리). 기절 면역. 목책 고리 반지름 14 안에서.
- **맞음 대기는 공격 출처마다**(대표 무기 · 절기 · 의용군 · 추가 초식 슬롯) — 서로 막지 않음(D-287).
- **경험치 구슬:** 줍는 거리 4, 떨어지고 25초 지나면 거리와 상관없이 빨려 옴 — 진영을 오가도 경험치를 안 잃게(D-291).
- **장수 시작 체력**은 데이터(관우 160 — 기절 · 의용군 같은 버티는 수단이 없어서, 장비 · 유비 100).

## 4. 구조 결정
- **절기는 독립 모듈**: `Ult`(`scripts/martial/ult_base.gd`)는 시전 맥락 ctx(origin · facing · horde · allies · atk_mul · evolved · spec)만 받는다. 장수 노드 · main에 기대지 않으므로 다음 단계의 '어시스트 호출'은 `main.cast_ult(id, origin, facing, evolved)`를 다른 위치 · 방향으로 부르면 된다.
- **적 · 의용군 · 구슬은 노드 없이 배열 + MultiMesh**(D-275 성능 결정을 그대로 따름). 의용군 모델은 황건적 스크립트의 변형(`--variant=militia`, 녹색 두건).
- **모든 수치는 데이터**: 장수(`heroes.gd`) · 절기(`ults.gd`) · 공통 규칙(`martial.gd`) · 추가 초식(`tactics.gd`) · 심법(`upgrades.gd`) · 웨이브(`waves.gd`). 남은 코드 상수: 장수 기본 체력 100 · 맞은 뒤 무적 0.35초 · 기본 이동 4m/s.
- **선택 화면**이 시작 장면(`scenes/select.tscn`). 판 옵션(`--hero` · `--auto` · `--bench` · `--test` · `--shots` …)이 있으면 건너뛰어 봇 · 점검을 그대로 쓴다. 고른 장수는 `HeroTable.chosen`(static var)로 넘김 — 자동 로드를 늘리지 않음.
- **효과**는 기본 도형 + `CPUParticles3D`(VFX 고도화는 범위 밖).

## 5. 확정된 결정 (2026-11-23, 1단계)
- 유비 의용군 소환 = **절기**(누적형). 장비 사자후 = **절기**. 관우 고유 심법 = **위풍**.
- 기존 책략 4종 → 추가 초식, 레벨업 능력치 → 심법으로 **편입**(용어만 바꿈, 오의 재료로 씀).
- 난이도 표기: 장비 ★ 입문 / 관우 ★★ / 유비 ★★★ 대기만성. 절기는 선택 카드에서 '???'.
- 밸런스 목표: 세 장수의 클리어 시간 · 생존율이 비슷하고, 유비는 초반 약세 → 후반 최강.

## 6. 폐기한 대안
| 대안 | 폐기 이유 |
|---|---|
| 책략을 무공과 별도 체계로 유지 | 오의 재료(초식 2 + 심법 1)를 따로 정의해야 하고 레벨업 카드가 두 갈래로 나뉨 |
| 유비 의용군을 자동 초식(시간마다 소환)으로 | 그러면 유비 절기를 새로 만들어야 하고, 내공을 모을수록 군대가 커지는 '대기만성' 곡선이 약해짐 |
| 장비 사자후를 자동 초식으로 | 장비 절기를 새로 만들어야 함. 기절 + 밀침은 '위기에서 빠져나오는' 절기에 맞음 |
| 관우 고유 심법 '의기'(처치 시 내공 +50%) · '청룡'(3번째마다 360° 휩쓸기) | '광역 · 묵직'에 가장 바로 맞는 건 범위 · 밀어내기(위풍) |
| 선택 결과를 자동 로드(싱글턴)로 넘김 | static var 하나로 충분 — 자동 로드를 늘리지 않음 |
| 작업 제목 '삼국봉크'를 게임 화면에 | 레퍼런스 게임 고유 용어(CLAUDE.md) |
| 진영을 깨는 것을 승리 조건으로(10분 타이머 없이) | 판 길이가 사람마다 달라지고 10분 + 보스 구조와 어긋남(사용자 선택: 진영 3곳 + 10분) |
| 적장을 적 떼 배열 안 특수 종류로 | 패턴 · 예고 · 체력 막대 · 2단계가 들어가면 배열이 복잡해짐 → 노드 하나 + `horde.targets` |
| 맞음 대기를 모든 공격이 공유(D-276~286) | 의용군 휘두름의 43%가 헛침, 초식끼리도 서로 막음 → 출처별 채널(D-287) |
| 진영 생성 30% | 적이 멀리서 늦게 와 처치 · 경험치가 줄어 6분 레벨이 크게 낮아짐(D-291) |
| 관우를 무기 수치로만 올림(휩쓸기 각 · 속도) | 쓰러지는 원인이 '버티는 수단 없음'이라 효과 적음 → 시작 체력 160 |
