## 1단계에서 남은 것 · 미검증
| 항목 | 상태 | 메모 |
|---|---|---|
| 사람이 직접 한 손맛(조작감 · 경공 타이밍 · 절기 체감) | **미검증** | 자동 봇 · 스크린샷으로만 확인 |
| 전체 난이도 | 봇 기준 맞춤(D-296) | 처음 해금 상태 9/12(관우 2/3 · 제갈량 3/3 · 유비 3/3 · 장비 1/3). 사람 기준은 미검증 |
| 장비가 가장 약함 | 남음 | ★ '입문'인데 봇 1/3(D-296) — 해금 장수라 다음 맞춤에서 |
| 제갈량 '붙으면 약함' | **미검증** | 체력 100 · 바람날 상향 뒤 봇 3/3 — 사람 손맛으로 확인 |
| 과제를 깨 가는 속도 | **미검증** | 사람이 몇 판 만에 장비 · 유비 · 무기를 여는지 |
| 바람 칼날 · 쌍고검이 잘 보이는지 | 일부(D-308) | 보이는 크기를 키움 — 기본 도형(세모 · 막대) 그대로 |
| 개그 동작 손맛 | **미검증** | GIF로만 확인. 사람이 해 보고 재미있는지 · 거슬리는지 |
| 여포 크기 2.0 · 맞는 반지름 1.0 | 남음 | 몸은 커졌는데 맞는 범위는 그대로 — 손맛으로 판단(D-310) |
| 매끈한 점토 질감 | 남음 | 설정화는 매끈, 모델은 저폴리 평면 음영(다른 모델과 맞춤) |
| 공용 무기 수치 | 일부 | 전고 오라 · 적토 화보가 약해 보임(D-294) |
| 유비 '후반 강세' 곡선 | 됨(D-293 · 296, 봇 기준) | 쌍고검 회선으로 다시 설계 — 9분 처치 15.1k~19.3k로 가장 높음 |
| 마우스 클릭으로 장수 고르기 | **미검증** | 숫자 키 흉내(`--select-test --select-key=N`)로만 확인 |
| 유비 이단 도약 포물선 | 일부 확인 | 경공 횟수 · 이동은 확인, 높이는 위에서 찍은 사진으로 구분이 어려움 |
| 실제 GPU PC · 웹 성능 | **미검증** | 의용군 MultiMesh 4개 · 파티클 추가 |
| 레벨업 카드의 '초식 · 심법' 용어 | 됨 | `main.gd _label`에서 표시만 바꿈(`tactics.gd` · `upgrades.gd` 파일은 그대로) |
| 어시스트 호출 | 다음 단계 | 절기는 독립 모듈(`Ult`, `main.cast_ult(id, origin, facing, evolved)`)로 준비만 됨 |
| 맞음 대기 공유 | **됨(D-287)** | 출처별 채널(대표 무기 · 절기 · 의용군 · 추가 초식 슬롯) |
| 경공 · 절기 몸짓(애니메이션) | 남음 | 효과(도형 · 파티클)만 있음 — VFX 고도화는 범위 밖 |
| 유비 보스전이 짧음 | **됨(D-293)** | 의용군 누적을 없애 여포 57~83초 |
| 여포 생김새 | 미검증 | 설정화 없이 글 설명으로 만듦 — GPT 설정화를 받으면 맞춤 |
| 적 종류 구분(위에서 볼 때) | 남음 | 노란 두건이 많아 궁병 · 방패병 구분이 아주 선명하진 않음 |
| 정예 · 보스 공격 몸짓 | 남음 | 예고 표시 · 걷기만 — 휘두르기 동작 없음 |
