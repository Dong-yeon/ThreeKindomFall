## 1단계에서 남은 것 · 미검증
| 항목 | 상태 | 메모 |
|---|---|---|
| 사람이 직접 한 손맛(조작감 · 경공 타이밍 · 절기 체감) | **미검증** | 자동 봇 · 스크린샷으로만 확인 |
| 전체 난이도 | **너무 쉬움(봇 기준)** | 3번째 맞춤에서 9판 모두 10분 클리어. 봇이 둘러싸일 때만 경공을 써 무적을 거의 완벽하게 받음(판마다 135~196번) — 사람 기준으로 다시 맞출 것 |
| 유비 '후반 최강' 곡선 | 됨(D-286, 봇 기준) | 1분 처치 182(가장 낮음) → 9분 17.9k(가장 높음, 관우 16.0k · 장비 15.3k). 3분은 1,750으로 관우(1,701)보다 약간 높음. 의용군이 이제 거의 안 쓰러짐(잃은 수 0) — 사람 손맛에서 너무 단단하면 회복 · 체력을 낮출 것 |
| 마우스 클릭으로 장수 고르기 | **미검증** | 1 · 2 · 3 키 흉내(`--select-test --select-key=N`)로만 확인 |
| 유비 이단 도약 포물선 | 일부 확인 | 경공 횟수 · 이동은 확인, 높이는 위에서 찍은 사진으로 구분이 어려움 |
| 실제 GPU PC · 웹 성능 | **미검증** | 의용군 MultiMesh 4개 · 파티클 추가 |
| 레벨업 카드의 '초식 · 심법' 용어 | 됨 | `main.gd _label`에서 표시만 바꿈(`tactics.gd` · `upgrades.gd` 파일은 그대로) |
| 어시스트 호출 | 다음 단계 | 절기는 독립 모듈(`Ult`, `main.cast_ult(id, origin, facing, evolved)`)로 준비만 됨 |
| 무기 · 절기 · 초식이 같은 '맞음 대기 0.3초'를 공유 | 일부 해결 | 의용군만 전용 맞음 대기로 분리(D-286). 장수의 대표 무기 · 추가 초식 · 절기끼리는 아직 공유 |
| 경공 · 절기 몸짓(애니메이션) | 남음 | 효과(도형 · 파티클)만 있음 — VFX 고도화는 범위 밖 |
